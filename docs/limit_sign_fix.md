# 限高牌数字显示问题修复

## 问题
自定义限高牌的数字和文字不可见。

## 根本原因
1. **字体渲染缩放过小** - `f = 0.02F` 使文字几乎不可见
2. **边缘抗锯齿不足** - `EdgeScale` 被设置为 1，但注释建议设为 4
3. **缺少纹理绑定** - 渲染前没有绑定字体纹理
4. **GUI 标签不够醒目** - 缺少颜色和粗体样式

## 修改内容

### 1. RenderHeightLimitSignCustom.java
- **提高渲染缩放比例**: `0.02F → 0.1F` (第57行)
- **调整 Y 轴位置**: `-0.3125F → -0.5F` (第51行)
- **添加纹理绑定**: 调用 `signFontRenderer.bindTexture()` (第62行)

### 2. SignFontLoader.java
- **提高边缘抗锯齿倍数**: `1 → 4` (第43行)
- 增强字符边缘平滑效果

### 3. SignFontRenderer.java
- **添加 `bindTexture()` 方法**: 确保渲染前绑定正确的纹理 (第138行)

### 4. GuiHeightLimitSignCustom.java
- **增强标签可见性**:
  - 添加黄色颜色 (`TextFormatting.YELLOW`)
  - 添加粗体效果 (`TextFormatting.BOLD`)
  - 调整位置以适应粗体文本

## 效果
- 限高牌上的数字和文字现在应该清晰可见
- 边缘抗锯齿效果更好，视觉更平滑
- GUI 界面标签更醒目

## 测试建议
1. 重启游戏
2. 生成限高牌
3. 检查方块上的数字是否可见
4. 打开 GUI 设置限高值，检查输入框是否可见

## 注意事项
- 如果文字仍然太小，可以进一步调整 `RenderHeightLimitSignCustom.java` 中的 `f = 0.1F` 为更大的值（如 0.15F）
- 如果文字太靠近边缘，调整 `y = -0.5F` 的值
