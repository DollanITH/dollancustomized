# 车站站名牌使用说明

## 概述
车站站名牌是一个贴在墙上的文字显示方块，适用于轨道交通车站内的站名牌标识。

## 功能特性
- 可自定义显示文字
- 支持字体大小选择（小号、中号、大号）
- 支持多种颜色选择（白色、黄色、红色、蓝色、绿色、橙色）
- 支持多种字体样式（大号、中号、小号）
- 贴在墙上显示，不影响通行

## 使用方法

1. **放置方块**
   - 将车站大字壁方块放置在墙上
   - 方块会自动贴在墙面并朝向玩家

2. **编辑内容**
   - 右键点击方块打开编辑界面
   - 在文本框中输入要显示的文字
   - 使用预设颜色按钮或RGB调节选择颜色
   - 点击字体大小按钮选择文字大小
   - 点击字体样式按钮选择字体

3. **颜色选择**
   - 支持RGB颜色系统，可自定义任意颜色
   - 预设颜色：白色、黑色、红色、绿色、蓝色
   - RGB调节：可以精细调整红、绿、蓝三个分量
   - 实时预览：修改时可以实时看到颜色效果

4. **字体大小**
   - 小号：适合短距离标识
   - 中号：标准大小
   - 大号：远距离可视

5. **字体样式**
   - 大号字体：大号显示，适合远距离观看
   - 中号字体：中等大小，平衡显示效果
   - 小号字体：小号显示，节省空间

## 技术实现
- 基于TileEntity实现数据存储
- 使用TESR（TileEntitySpecialRenderer）进行渲染
- 支持网络同步，多人游戏时数据同步
- 渲染距离优化，远距离清晰可见

## 注意事项
- 方块必须贴在平整的墙面上
- 文字长度建议控制在10个字符以内以保证清晰度
- 大号字体在远距离效果最佳
